# SIP-Calculator — Advanced SIP vs. Lumpsum Financial Analytics Dashboard

A modern, high-precision financial analytics web application built to compare **Systematic Investment Plans (SIP)** and **Lumpsum** investment strategies while factoring in the critical impact of **Inflation** on real purchasing power.

## 🚀 Key Features

* **Dual Strategy Engine:** Instantly toggle between **SIP Mode** and **Lumpsum Mode** to analyze compounding differences.
* **Inflation Adjustment Modeling:** Calculates real purchasing power using the present-value formula: 
  $$\text{Real Value} = \frac{\text{Nominal Future Value}}{(1 + i)^n}$$
* **Smart Strategy Recommendation Engine:** Automatically evaluates and highlights which investment strategy wins based on your custom horizon, return rate, and inflation inputs.
* **Dynamic Visualizations:** Powered by **Chart.js** featuring real-time decomposition doughnuts and year-by-year multi-line growth curves.
* **Interactive UI/UX:** Built with **Tailwind CSS**, custom-styled range sliders with track fill logic, and responsive dark-mode glassmorphism styling.
